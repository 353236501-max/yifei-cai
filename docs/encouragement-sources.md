# 鼓励语设计说明

网页中的鼓励语是本项目原创改写，参考公开教育资料中关于成长型心态、具体目标、策略调整、及时反馈和适度休息的建议，没有复制文章或名人语录。

参考入口：

- APA，Thinking and Learning：<https://www.apa.org/ed/schools/teaching-learning/top-twenty/thinking-learning>
- APA，Motivation Myth Busters：<https://www.apa.org/ed/schools/myth-busters>
- IES，Understanding Academic Mindsets：<https://nces.ed.gov/learn/blog/understanding-academic-mindsets>
- MIT Teaching + Learning Lab，Growth Mindset：<https://tll.mit.edu/teaching-resources/inclusive-classroom/growth-mindset/>
- 中国大学生在线，考研学习支持文章：<https://dxs.moe.gov.cn/zx/a/fdy_bjtj_xgxs/241204/1982840.shtml>

应用原则：称呼“早觉雨大人”；每段最多一处鼓励；把鼓励连接到当前步骤；不以分数、排名或他人进度制造压力；允许休息，并把错误转化为下一步的线索。
