# 2026-09-29 内置课程与 API 更新

早觉雨大人，当前版本覆盖全部 35 个目录主题，包含 36 份原创复习单元、72 道独立强化与迁移题。默认讲解、题目、提示、解析内置于网页，不再要求导入本地 PDF 或先配置模型。

来源、覆盖范围和验证记录见 [内置课程验收](embedded-study-release.md)，原页核对清单见 [来源页记录](pdf-sources-reviewed.json)。参考文件的考点用于原创整理，关联内容明确标注为延伸，不将生成内容冒充 PDF 原文。

公式统一经 Markdown 数学解析与 KaTeX 渲染；修复多行美元定界符吞入后续正文的问题，并兼容 LaTeX 圆括号、方括号公式边界。1,105 个内置公式片段通过渲染核对。长公式可在本区域横向滚动。

AI 追加讲解和出题由服务端读取内置资料，无正文摘录时也可以发起；私有附加摘录仍须外发确认。默认学习页面不会调用本机 PDF 搜索。旧简单模板从学习入口移除。

此前 API 修复包括端点规范化、空白密钥处理、服务商匹配、超时与脱敏错误。新增路由测试验证不导入 PDF 时可发送内置课程上下文，且 DeepSeek 不会重复拼接路径。测试用替代网络响应；真实 DeepSeek 请求此前因本机出站网络超时，云端真实调用仍未确认，不把测试响应视为服务商成功结果。

Lean 未运行，SymPy 未运行；部分题目用独立数值积分、矩阵运算和算法模拟核对。资料与解析仍可持续接受人工审校。
