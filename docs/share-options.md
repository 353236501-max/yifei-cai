# 可分享形式

早觉雨大人的自习室可以用以下方式分享给他人，所有方式都支持使用者在自己的浏览器中填写 API Key。

## 1. 一键本地包（推荐隐私优先）

把 `gentle-tutor` 文件夹和项目根目录的 `启动自习室.cmd` 一起压缩。对方安装 Node.js 22.13+、Python 3.10+ 与 `pypdfium2` 后双击启动文件，在 `http://localhost:5173/` 使用。PDF 和错题留在对方电脑上，API Key 只在当前页面内存中使用。

## 2. Docker Compose（推荐跨平台）

后续可提供包含网页服务和本地资料服务的 `docker compose up` 包。用户只需安装 Docker Desktop，API Key 仍由每个使用者自行填写；知识库目录通过只读挂载提供给容器。

## 3. 局域网分享

开发服务监听 `0.0.0.0:5173` 后，同一 Wi-Fi 的设备可通过主机局域网地址访问。此方式不需要外部账号，但不适合公网访问。

## 4. 公网托管

可以使用 Sites、Cloudflare Pages、Vercel 或自有服务器。公网版本不应内置个人 API Key；使用者填写自己的 Key，服务端只处理本次请求，并继续保留本地证据发送确认。

## API 配置约定

- 使用者自行选择 DeepSeek、通义千问、硅基流动或兼容 Chat Completions 的服务。
- API Key 不写入 URL、错题记录、知识库或分享包。
- 公开部署时限制可访问的 HTTPS 域名，拒绝本机地址和明文 HTTP 转发。
- 本地资料默认不上传；只有用户明确勾选引用后，才把选中的短摘录发给模型。
