# 早觉雨大人的工作台：实现与验证记录

更新：2026-09-25。早觉雨大人，当前交付是可交互的私人学习工作台首版，下面区分实际完成和需要额外环境的部分。

## 已实现

- 从上传的两份考纲整理 35 个大主题。目录并不意味着各主题的所有细知识点已经完整编写；当前每个主题提供一份原创入门讲解和一道参数化练习模板。
- 课程筛选、知识点选择、主题内搜索；概念、直觉、考纲、教材主题映射、易错点、参考链接。
- 35 组原创基础练习模板、数字/分数答案检查、分步解析、两道参数变式。不是历年真题题库；来源字段不虚构年份与题号。
- 练习层已升级为考研强化：默认题目要求展开、条件辨析、综合判断或算法/系统约束分析；每道题仍保留参数化变式和两道举一反三题，页面不再把题目标成“基础”。
- 知识讲解层以本地 SQLite FTS5 页码检索为入口，用户可先核对原页，再将短摘录带入模型；没有本地证据时才回退到内置考纲讲解。
- 新增“资料驱动讲解与命题”工作项：知识讲解优先引用用户提供 PDF 的文件名、物理页码和短摘录；变式练习优先沿用 PDF 中的考点、方法链和题型结构，再改变数值、条件、情境或问法。来源明确且版权允许时可以展示原题摘要或原题讲解；来源不明时标为低置信度并要求人工复核，原题、原创改编题和自编综合题在界面上分开标识。
- KaTeX 公式、导数切线交互图、GeoGebra/Desmos 入口、Manim 源码示例。
- 错题图片本地预览、手工输入、可能错因记录；AES-256-GCM 加密文字与图片。随机 IV，身份与记录 ID 绑定为 AAD。D1 存加密记录，R2 存加密图片。服务端按身份限制读写，删除联动对象删除。
- FSRS 5.x 复习安排，使用真实 ts-fsrs 算法；版本号检查避免并发覆盖。无虚构学习天数和排行榜。
- 千问、DeepSeek、硅基流动及允许域名的兼容接口；独立文本/视觉模型配置；DashScope 原生联网检索适配器。密钥在页面内存中，刷新清除，通过服务端转发；外发图片需本次勾选同意。未提供有效密钥，故这些服务没有做真实账号调用验收。
- B 站只提供官方搜索，未人工审核的 UP 主与时间戳不推荐，不下载或截取媒体。
- 四个原创 408 实验：BFS C++、Cache Python、Linux fork/wait、TCP 回环收发。提供 Dockerfile、步骤、预期输出、排错与断言。进阶工具仅官方入口和方向，未托管远程终端或启动模拟器。
- 系统中文语音朗读，优先选择可用中文女声；无系统中文声库时提示。未部署 GPT-SoVITS、CosyVoice 或 edge-tts 服务。
- 浏览器 Worker 中实际加载 Pyodide 0.27.7 / SymPy 1.13.3，检查内置数学练习，90 秒超时终止；仅执行作者限定操作，不执行任意输入代码。Lean 的独立 Docker 验证入口见 verification/，当前未运行。

## 架构与限制

独立 React / Vinext 前端 + Cloudflare Worker API，Sites 私人身份，D1 + R2。阶段 0 的 LibreChat 复用建议属于候选方案；本次按直接交互产品需求选择轻量独立界面，未声称已经集成 LibreChat 或 Dify。本地新增 Python PDFium 提取服务 + SQLite FTS5 页码检索；以短摘录增强回答，不使用向量数据库。内置考纲通过明确的当前主题上下文提供给模型；不把它称为向量检索。

本机预览使用 starter 的本地模拟账号，生产依赖平台注入的已登录身份。服务端不接受浏览器自报 owner。生产密钥通过 Sites Secret 配置，本地 .env 被版本控制忽略。长期密钥轮换需要另行设计重加密流程，不应直接覆盖 STORAGE_KEY 导致旧数据无法解密。

模型文本和用户上传数据均是不可信内容，不允许覆盖系统教学规则。Markdown 不渲染原始 HTML，不加载模型生成的远程图片。搜索响应的源链接单独保留；搜索服务返回来源不等于已确认真题出处，置信度默认低，年份/题号/学校未知时保持未知。

图片永久删除指应用活动数据与对应对象，不承诺平台备份介质的即时物理擦除。没有模型密钥时，不会把“识别成功”当作演示填充。数值检查不能替代证明，形式文件通过也必须人工核对命题和题意。
