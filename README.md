# 雨知 · 早觉雨大人的温柔自习室

Cloudflare 公网部署请按 [Workers 部署说明](docs/cloudflare-deploy.md) 设置：构建 `npm run build`，部署 `npm run deploy`。

早觉雨大人，网页现在优先使用这个项目里的本地资料。你可以先检索、核对原页，再把选中的短摘录带入提问。

## 一键启动

在项目根目录双击 **启动自习室.cmd**，保持启动窗口打开，然后访问 **http://localhost:5173/**。当前电脑的 Node 和 Python 会自动定位；也可以在 gentle-tutor 目录运行：

```sh
node scripts/start-local.mjs
```

首次换电脑需要 Node.js 22.13+、Python 3.10+、pypdfium2（本机验证版本 5.13.0），执行 npm install 安装网页依赖。可用 TUTOR_PYTHON 指定 Python 路径。启动程序只启动未占用的端口，不会终止已有程序。5173 是网页，8765 是本地文件服务，均只监听本机；请勿将开发预览暴露到公网。

## 本地知识库

1. 把 PDF、DOCX、TXT、MD 放在项目目录内，也可在书架点击“导入新资料”（单文件最多 300 MB）。
2. 服务每 60 秒检查新增、修改和移除；也可以点击“更新目录”。重新提取不会修改原文件。
3. 输入关键词，点击“检索页内内容”，用“核对原页”检查公式与题干。页码指 PDF 物理页码，Word / 文本使用分段编号。
4. 点击“引用提问”，核对短摘录并明确允许发送后，再调用模型。未勾选前不会发送摘录。
5. 扫描页先打开原页，点击“准备识别这一页”；在模型设置选择支持图片的模型，同意发送这一页。识别后校正文字，再点击“确认文字并更新本地索引”。

早觉雨大人，扫描件不会被冒充为已识别文本。有文字层也可能遗漏公式；对数学推导仍需核对原页。文件名中的年份和卷种只是初步推断，不等于官方真题来源。重复片段会合并检索展示。

本地索引位于 gentle-tutor/.sites-runtime/library，原教材与索引不上传到托管网站。内置 35 个课程主题仍保留，作为没有检索结果时的原创入门学习材料。当前检索是 SQLite FTS5 关键词检索，不是向量检索。

## 模型设置

### 分享给他人

发布后的网页可以直接分享给其他学习者。课程讲解、考研强化练习、BYOK 模型对话、错题和复习不要求 ChatGPT 登录；每个浏览器首次打开时生成独立的本地访客标识，因此每个人只能看到自己浏览器保存的内容。每位使用者填写自己的 API Key，Key 只随本次请求使用，不会写入记录、分享链接或仓库。访客标识适合私下分享，不是强身份认证；若清除浏览器 Cookie，该浏览器的记录将无法找回。

支持千问、DeepSeek、硅基流动以及兼容 Chat Completions 的服务。填写服务地址、文本模型 ID、可选图片模型 ID 和自己的 API Key；模型 ID 以服务商当前控制台为准。“读取可用模型”可获取该账号的模型列表，但列表不代表所有模型支持图片。

- 默认允许千问北京/国际、DeepSeek、硅基流动官方 API 域名。
- 其他公网域名需由部署者加入 .env 的 MODEL_ALLOWED_HOSTS（逗号分隔），重启网页；只允许 HTTPS，不接受本机/IP 地址、不跟随重定向。
- Key 只存在当前页面内存，刷新清除，不保存到数据库。切换服务或地址会清空 Key。
- 千问提供原生联网检索；其他兼容服务使用本地证据，不冒充自带联网能力。
- DeepSeek 预设没有图片模型。OCR 需选择服务商实际支持视觉输入的模型。

没有真实 Key 时仍能使用本地检索、课程、原创练习、错题记录和复习。API 适配器已实现，但真实模型的 OCR、自由问答、搜索仍需有效账号完成验收。

## 学习功能

知识讲解、35 组原创基础题模板与变式、KaTeX 公式、交互切线图、错题加密保存、FSRS 复习，以及四个可下载的 408 实验。B 站仅官方搜索入口，具体视频需人工审核。语音使用系统中文声库。

数学练习可运行浏览器 SymPy 检查；Lean 独立入口在 verification/，本机没有 Docker / Lean，未声称证明通过。数值检查不能替代数学证明。

## 数据与验证

.env 的 STORAGE_KEY 用于加密错题文字及图片，不要覆盖或丢失。原始教材沿用本机文件权限；索引也是本地明文文本，不属于加密错题存储。保存图片不自动外发；删除错题会联动删除对应图片。
